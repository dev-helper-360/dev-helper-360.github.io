JSON 포매터 / 뷰어

JSON 데이터를 읽기 쉽게 포맷팅하고 구문 오류를 검증합니다.

JSON을 입력하고 포맷팅 버튼을 클릭하세요.

💡 사용법
  • 포맷팅: JSON 텍스트를 입력하고 "포맷팅" 버튼을 클릭하면 읽기 쉽게 정리됩니다.
  • 검증: JSON 구문에 오류가 있으면 오류 메시지가 표시됩니다.
  • 압축: 포맷팅된 JSON을 한 줄로 압축할 수 있습니다.
  • 샘플 데이터를 로드하여 기능을 테스트해보세요.
💡 How to Use
  • Formatting: Enter JSON text and click "Format" to make it readable.
  • Validation: Syntax errors will be displayed if found.
  • Minification: Compress formatted JSON into a single line.
  • Load sample data to test the functionality.
